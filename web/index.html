JETRIS

A real-time multiplayer, guideline-style cooperative/competitive block-stacking game — and a peer-to-peer distributed blackboard system built with nothing but NATS JetStream. If you like it, give it a ⭐ on GitHub!

Runs as WebAssembly right here, nothing to install. This page is served over https, so the NATS server you pick on the login screen must speak wss:// — the public demo.nats.io server is preselected.The NATS server you pick on the login screen must have a WebSocket listener (ws:// or wss://). For nats:// servers, your NATS CLI contexts, or a LAN party with an embedded server, grab a desktop build.
